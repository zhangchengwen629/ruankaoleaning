# C / C++ 练习

- `c/`：C 语言练习，文件后缀 `.c`。
- `cpp/`：C++ 练习，文件后缀 `.cpp`。

## 在 VS Code 中运行

1. 用 VS Code 打开整个 `ruankaoleaning` 文件夹。
2. 打开要运行的 `.c` 或 `.cpp` 文件，保存修改，并保持该文件是当前编辑器标签。
3. 在“运行和调试”中，按语言选择 `Debug current C file` 或 `Debug current C++ file`。
4. 按 F5 编译并调试，或按 Control+F5 运行而不调试。输出和键盘输入位于终端。

可以在两个目录中自由新增练习文件，也可以按章节建立子目录。每个练习文件独立编译，各自包含一个 `main` 函数。编译产物放在源文件旁的 `.build/` 中，不会提交到 Git。

当前配置用于 macOS 的 Apple Clang、C17 / C++17 和 CodeLLDB 扩展，仅编译当前文件；以后编写多个源文件共同组成的程序时，需要调整构建配置。
